# Tシャツ3Dプレビュー：検証メモ

## 動作

アートでTシャツのパーツを開くと「3Dプレビュー」を表示する。現在の面は未保存の画素を使用し、他の面は互換性のある保存済み作品を利用者が選ぶ。未設定面は白。前後左右・初期方向、手動回転、明示的な自動回転、色確認モードを搭載。

Three.js 0.185.0はjs/vendor/threeへMITライセンスとともに固定配置。公式npm配布物を利用し、初回クリック時に遅延読み込み。

既存の下書き、保存作品、共有コードv1の形式は変更していない。プレビューの面選択はセッション内のみ。初回取得した3Dアセットは既存Service Workerのネットワーク優先キャッシュを利用する。未取得のままオフラインの場合は読込失敗を通知する。

## 実施済み

```sh
node --experimental-vm-modules --test tests/art-3d.test.mjs
node --check js/art-3d-adapter.js
node --check js/art-3d-preview.js
node --check js/art-3d-models/tshirt.js
```

- 2つの自動テストが成功。頂点・法線・UVの有限性、UV範囲、index範囲、裏地と各部位の存在、キャッシュした形状のバッファ独立性を検査。
- 未保存の現在画素の優先、保存済み面の明示選択、寸法不一致の除外、未設定面、非対応衣装への切替時の閉じる処理を検査。
- adapterが保存データを変更せず、storageへ書き込まないことを検査。
- 形状生成は約11.3万頂点・22.4万三角形・12部位。検証環境で初回生成は約2秒。実機の描画速度は未測定。

## 未実施と制限

検証環境のブラウザからローカルサーバーへ接続できず、ローカルブラウザの追加取得も失敗したため、実ページでのWebGL・ダイアログ・タッチ・オフラインの統合確認は未実施。

モデルには胴・左右袖・裏地・縁を含む。表面の布材質、布目の凹凸、周辺画素の延長、裏地の主要色表示を適用する。色確認モードは白重ね・照明の影響を抑える。ゲーム内との一致は実機での確認が必要。布物理・人物モデルは含まない。UIはTシャツのみ対応。

初回の形状生成は同期処理で、低性能端末では待ち時間が長くなる可能性がある。以降の開き直しは形状キャッシュを使い、編集時はtextureのみ更新する。

## マージ前の画面確認

1. Tシャツの各面へF/B/L/Rと矢印・番号入り格子を描き、前後左右から向きと位置を確認する。
2. 背面・袖の保存済み作品を選び、現在編集中の作品や保存作品が変更されないことを確認する。
3. 開く・閉じるを繰り返し、Escape、フォーカス復帰、画面回転、モバイルのスクロールを確認する。
4. プレビューを開いた状態でUndo/Redoの変更が反映されることを確認する。
5. 3Dで矢印キーやドラッグが動き、2Dに誤描画しないことを確認する。
6. 3Dを一度開いた後のオフライン再表示、初回オフライン時のエラー、WebGL不可時の2D継続を確認する。
7. iPad/iPhoneのSafari、PRISM内等での利用が必要なら各環境で確認する。

公開サイトへはマージ後に配信される。ドラフトPR作成だけでは本番へ反映されない。
